# Reporting a security issue

Use GitHub's private vulnerability reporting feature on the repository when available. If it is unavailable, contact the repository owner privately before sharing an exploit publicly. Never put credentials, private customer reviews or confidential data in an issue.

Model artifacts are local and bundled with the recorded experiment. Load `joblib` or PyTorch pickle files only from a trusted source; serialized Python objects can execute code when loaded. Verify the included artifact manifest before using distributed weights. Fine-tuned transformer weights use safetensors. Checksums detect unintended changes but do not establish the trustworthiness of a publisher.

The CLI performs local inference and requires no API key or hosted inference service. The evaluated scope is English product-review sentiment, with the limitations documented in the report.
